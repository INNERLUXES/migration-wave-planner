# A clean inventory

Larkspur, a made-up clinic, with an inventory ready to plan. Every workload has an owner and one of the 7 Rs, every
dependency names a workload of the file, nothing depends on the fax server marked retire, and the imaging archive that
stays behind depends on the directory service but nothing that moves depends on it. The plan has four waves: the
directory service first, then the file share and the records database, then the records application, and then the
booking and the lab gateway. The estate key is not a key the tool reads.
